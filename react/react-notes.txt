5) Modular css: it is used when we have a single .css file and there are multiple styles with the same name.
So what to do in this situation: 
1) Create seprate css files for each component and follow the compulsory naming convention: Component.modular.css;
2) import in the .jsx file where it will be used, for eg: import style from './..Component.modular.css'
3) use it in the component where it is required: `{style['style-name']}`
